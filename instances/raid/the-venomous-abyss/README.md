# 烈毒之渊 (The Venomous Abyss) 团队副本总览与开荒指南

## 1. 基础信息

- **英文名称**：The Venomous Abyss
- **WCL Zone ID**：53
- **首领总数**：6 位
- **史诗团队配置**：2 坦克 + 4 治疗 + 14 输出（开荒基准）；中前置首领在伐木期可压缩为 3 治疗。
- **环境机制**：高频腐蚀毒液、暗影易伤、流血撕裂与场地深渊坠亡机制。

---

| 增益类型 | 核心职业 | 战术价值与入选理由 | 史诗开荒刚需等级 |
| :--- | :--- | :--- | :--- |
| **5% 智力光环** | 法师 (奥法/冰法) | 提升全团法系秒伤与治疗法力周转 | **S 级刚需** |
| **5% 物理易伤** | 武僧 (踏风/酒仙) | 提升近战物理菜刀输出 | **S 级刚需** |

| **天怒图腾 / 风怒图腾** | 萨满祭司 (元素/增强) | 提升武器战平砍与全团法系爆发 | **S 级刚需** |
