# 虚空之痕竞技场 (Voidscar Arena) 机制总览与攻略索引

## 1. 基础信息

- **英文名称**：Voidscar Arena
- **限时基准**：31:00（1860 秒）
- **主要伤害类型**：暗影穿透、虚空引力撕裂、高频物理投掷
- **核心驱散需求**：**魔法驱散 (Magic Dispel)**（全团暗影 Dot）、群控打断
- **推荐队伍功能性**：
  - 团队魔法大减伤（死亡骑士大罩、圣骑士虔诚光环）；
  - 远程短 CD 打断（萨满风剪、法师反制）；
  - 强制位移技能（血魔之握、台风）聚拢散落的虚空法系怪。

---

## 2. 首领概览

1. **1 号首领：角斗坑冠军 (The Pit Champion)**
   - 核心机制：狂怒战斧点名最远距离队员，地面留下旋转飞斧；震地裂隙形成大面积暗影死区，需沿场地边缘顺时针带位。
2. **2 号首领：裂隙编织者卡伦 (Riftbinder Karen)**
   - 核心机制：场中生成虚空引力黑洞，全员被强制吸附；转阶段召唤 3 只虚空畸体，必须迅速单点击杀。
3. **3 号首领：吞虚巨兽 (Void-Gorged Behemoth)**
   - 核心机制：全屏吞噬狂潮（高频全团暗影尖刺）；正面虚空吐息（附带 100% 破甲易伤）；狂暴阶段全场生成移动黑球。
