# 密谋小径 (Murder Row) 机制总览与攻略索引

## 1. 基础信息

- **英文名称**：Murder Row
- **限时基准**：32:00（1920 秒）
- **主要伤害类型**：暗影刺杀、重度物理穿透、酸液剧毒
- **核心驱散需求**：**流血减免 (Bleed)**、**魔法驱散 (Magic)**
- **推荐队伍功能性**：
  - 反潜显形技能（猎人照明弹、恶魔猎手幽灵视觉）；
  - 强力物理减伤护甲技能应对行刑官连击；
  - 窄道聚怪技能（死亡骑士血魔之握、武僧平心之环）。

---

## 2. 首领概览

1. **1 号首领：夜行者里克丝 (Nightstalker Rix)**
   - 核心机制：暗影步伏击最远距离队员；全场释放烟雾弹（进入烟雾无法施法，需迅速走位离开）；毒刃投掷造成减速与流血。
2. **2 号首领：暗谷男爵 (Baron von Shadowglen)**
   - 核心机制：灵魂榨取（吸取全队生命并给首领套护盾，必须在 8 秒内打碎护盾打断读条）；召唤吸血蝙蝠，需聚怪顺劈。
3. **3 号首领：刽子手韦恩 (Executioner Vane)**
   - 核心机制：斩首行刑（坦克极限死刑，造成 200 万物理直伤，必须覆盖大免伤）；铁链绞杀点名两名队员拉向断头台中央。
