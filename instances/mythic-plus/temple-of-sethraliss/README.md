# 塞塔里斯神庙 (Temple of Sethraliss) 机制总览与攻略索引

## 1. 基础信息

- **英文名称**：Temple of Sethraliss
- **所属资料片**：争霸艾泽拉斯 (Battle for Azeroth)，当前回归至暗之夜第二赛季钥石轮换池
- **限时基准**：35:00（2100 秒）
- **主要伤害类型**：自然闪电、剧毒穿透、高额全团法术震击
- **核心驱散需求**：**中毒驱散 (Poison)**（神经毒素）、**疾病驱散 (Disease)**、**受控挡线**
- **推荐队伍功能性**：
  - 强力治疗爆发（尾王救赎治疗战）；
  - 远程短 CD 打断控制；
  - 强控眩晕应对小蛇群。

---

## 2. 首领概览

1. **1 号首领：阿德里斯和阿斯匹克斯 (Adderis & Aspix)**
   - 核心机制：双首领轮换【静电护盾】。带护盾的目标受攻击时会对全团反弹高额闪电伤害，全队必须转火攻击无护盾目标。
2. **2 号首领：米利克萨 (Merektha)**
   - 核心机制：盲目之沙（全屏致盲读条，读条结束瞬间必须背对首领）；缠绕毒蛇结（迅速顺劈解救队友）；剧毒吐息。
3. **3 号首领：加瓦兹特 (Galvazzt)**
   - 核心机制：场地四周不断向首领发射充能闪电线，首领充能满 100 触发全灭爆震。全员必须轮流肉身挡线截断充能。
4. **4 号首领：塞塔里斯的化身 (Avatar of Sethraliss)**
   - 核心机制：纯治疗拯救战。治疗团队通过刷血将化身血量从 0 抬至 100% 获胜，期间 DPS 负责清理腐化巫妖与青蛙。
