# 夺目谷 (The Blinding Vale) 机制总览与攻略索引

## 1. 基础信息

- **英文名称**：The Blinding Vale
- **限时基准**：30:00（1800 秒）
- **主要伤害类型**：自然、剧毒、物理穿刺
- **核心驱散需求**：**中毒 (Poison)**（刚需，全队毒性叠层极快）、**诅咒 (Curse)**
- **推荐队伍功能性**：
  - 拥有清毒技能的治疗（神圣骑士、恢复萨满、织雾武僧）或辅助职业；
  - 强控眩晕图腾、盲目之光应对潜行伏击怪；
  - 战复与 1 分钟短爆发职业（契合林间波次节奏）。

---

## 2. 首领概览

1. **1 号首领：郁林守护者瓦伦 (Gloomtender Valen)**
   - 核心机制：腐蚀花粉点名向外侧分散排毒；全团缠绕荆棘需顺劈迅速转火击破；首领读条自然巨浪时必须规避正面扇形。
2. **2 号首领：荆棘之母布赖尔 (Thornmother Briar)**
   - 核心机制：全团持续性荆棘流血 Dot（不可驱散，治疗压力极大）；召唤爆裂树苗，树苗靠近首领时会自爆灭团，需减速拉开控制。
3. **3 号首领：盲眼之王 (The Blind King)**
   - 核心机制：致盲回声全场暗黑点名；正面回声重击（坦克死刑，叠加 80% 破甲易伤）；震耳咆哮需全员在施法完成瞬间背对或规避正面音波球。
