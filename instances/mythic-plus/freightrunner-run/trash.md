## 2. 打断与自爆车控制链分配

### 紧急修理 (Emergency Repairs) 盯防链
- **1 棒**：近战 DPS（责难 / 心灵冰冻 / 拳击），读条半程打断。
- **2 棒**：远程 DPS（风剪 / 反制）或坦克，打断二次读条。
- **群体补断**：多只技师合波时，由武僧【扫堂腿】或恶魔猎手【混乱新星】群体截断。

### 自爆车控场与阻滞责任表
- 萨满【地缚图腾】、德鲁伊【纠缠根须/台风】、猎人【焦油陷阱】必须在自爆车刷新时第一时间减速。
- 严禁坦克将其拉入近战堆，近战输出切忌贴脸打平砍。

## 3. 新人易错与防暴毙自查

1. **自爆车冲进人群炸死全队**：小怪群中混入自爆车，全队无人交减速，自爆车撞向坦克引发范围连环爆炸直接团灭。
2. **技师无限加血打不掉**：打断技能全交在无意义的火球上，技师连续读出 3 次紧急修理把大怪血量全部奶满。
3. **监工正面击飞坠崖**：站台边缘无护栏，近战站在监工正面被高压鞭笞击飞掉出轨道坠亡。
