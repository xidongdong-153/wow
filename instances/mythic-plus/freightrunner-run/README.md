# 运货快道 (Freightrunner's Run) 机制总览与攻略索引

## 1. 基础信息

- **英文名称**：Freightrunner's Run
- **限时基准**：30:00（1800 秒）
- **主要伤害类型**：物理穿透、火焰高温、电弧震击
- **核心驱散需求**：**激怒驱散 (Enrage)**、**昏迷强打断**
- **推荐队伍功能性**：
  - 强力减速与范围昏迷控制，阻止自爆小车靠近；
  - 强断读条技能阻止地精技师修理回血；
  - 团队火焰与物理大减伤。

---

## 2. 首领概览

1. **1 号首领：走私女王维萨 (Smuggler Queen Veesa)**
   - 核心机制：双持速射（坦克流血）；走私炸药桶点名（点名者抱桶放置在场边，严禁在场中引爆）；烟幕弹消失偷袭后排。
2. **2 号首领：铁甲无畏号 (Ironbound Dreadnought)**
   - 核心机制：蒸汽重击（坦克死刑，击退 15 码）；全场发射地雷（触碰爆炸，需排雷）；超载过热（全屏极高火焰 AOE）。
3. **3 号首领：过载者格博 (Overcharger Gebbo)**
   - 核心机制：过载电弧链（全员保持 6 码分散，防止电弧弹跳死人）；发电机充能阶段需全队转火击毁 4 个电容发生器。
