# 阿曼尼地穴 (Amani Crypts) 机制总览与攻略索引

## 1. 基础信息

- **英文名称**：Amani Crypts
- **限时基准**：34:00（2040 秒）
- **主要伤害类型**：暗影穿透、巫毒诅咒、穿刺物理伤
- **核心驱散需求**：**诅咒驱散 (Curse)**（极高优先级，腐烂诅咒致死）、**魔法驱散 (Magic)**
- **推荐队伍功能性**：
  - 拥有解除诅咒技能的职业（萨满净化灵魂、法师解除诅咒、德鲁伊清除腐化）；
  - 群体击退与昏迷（防止木乃伊群扑倒后排）；
  - 持续范围 AOE 职业清除复生骷髅海。

---

## 2. 首领概览

1. **1 号首领：巫医特卡拉 (Witch Doctor T'Kala)**
   - 核心机制：插下巫毒图腾（吸取全员属性强化自身，需第一时间转火）；衰弱诅咒降低目标 50% 移速与伤害；暗影幽魂随机点名追人。
2. **2 号首领：地穴领主马洛尔 (Crypt Lord Malor)**
   - 核心机制：地穴穿刺（地面尖刺连续喷发，全员横向规避）；甲壳硬化（施法期间首领获得 80% 反伤，输出必须立即停手）；释放腐肉甲虫群。
3. **3 号首领：祖阿曼残响 (Zul'Aman Remnant)**
   - 核心机制：远古战嚎全屏高额物理恐惧震荡；黑暗复生阶段召唤历代巨魔先祖幻影，需集中聚怪顺劈。
