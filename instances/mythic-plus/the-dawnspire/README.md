# 晨曦尖塔 (The Dawnspire) 机制总览与攻略索引

## 1. 基础信息

- **英文名称**：The Dawnspire
- **限时基准**：33:00（1980 秒）
- **主要伤害类型**：神圣穿透、灼热火焰、高额物理重击
- **核心驱散需求**：**魔法驱散 (Magic)**（烈阳灼烧 Dot 叠加减速与神圣易伤）
- **推荐队伍功能性**：
  - 团队魔法大减伤（死亡骑士大罩、圣骑士虔诚光环）；
  - 强力位移加速（风行图腾、咆哮）应对激光扫射；
  - 稳定打断分配阻止圣光祷言大回血。

---

## 2. 首领概览

1. **1 号首领：日曜守卫索伦 (Solar Guardian Solenn)**
   - 核心机制：日光充能（能量达到 100 触发全团持续高压神圣 AOE）；灼热重击（坦克死刑，附加 100% 神圣易伤）；烈阳火柱点名分散。
2. **2 号首领：烈阳执政官 (Archon of the Sun)**
   - 核心机制：晨曦射线全场 360 度顺时针旋转激光扫射（触碰即秒杀）；纯净护盾需全员转火打破。
3. **3 号首领：高阶裁决者奥蕾莉亚 (High Arbiter Aurelia)**
   - 核心机制：审判天平（点名 2 名队员分别附带日光与月影印记，需迅速靠近对撞消除）；全屏落剑矩阵需快速找安全空隙走位。
