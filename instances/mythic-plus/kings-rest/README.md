# 诸王之眠 (Kings' Rest) 机制总览与攻略索引

## 1. 基础信息

- **英文名称**：Kings' Rest
- **所属资料片**：争霸艾泽拉斯 (Battle for Azeroth)，当前回归至暗之夜第二赛季钥石轮换池
- **限时基准**：39:00（2340 秒）
- **主要伤害类型**：暗影、重度剧毒、尖刺物理流血、昏迷控制
- **核心驱散需求**：**中毒驱散 (Poison)**（暗影妖毒）、**流血硬免伤**
- **推荐队伍功能性**：
  - 强力物理防猝死光环；
  - 瞬发爆发转火能力（快速开棺救人）；
  - 驱散与风筝能力应对部族议会。

---

## 2. 首领概览

1. **1 号首领：黄金风蛇 (The Golden Serpent)**
   - 核心机制：吐金点名（排在场地外圈金色水池）；召唤黄金活体，需顺劈迅速转火；卢彻的召唤造成全屏风暴。
2. **2 号首领：殓尸者姆沁巴 (Mchimba the Embalmer)**
   - 核心机制：枯萎病菌点名（持续高额暗影流血）；石棺埋葬（将 1 名队员关入 4 个石棺之一，其余队员必须快速点开正确石棺救人）。
3. **3 号首领：部族议会 (The Council of Tribes)**
   - 核心机制：依次激活 3 位巨魔督军（屠夫库拉、征服者阿卡阿里、智者扎纳扎尔），考验斩首顺劈规避与图腾秒杀。
4. **4 号首领：达萨，始祖之王 (Dazar, The First King)**
   - 核心机制：旋风斩全场移动；猎头者长矛锁定点名；转阶段召唤两头巨型风蛇战宠。
