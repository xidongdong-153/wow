# WCL 代表性顶尖冰霜死亡骑士日志拆解与复盘

## 1. 大秘境世界顶尖选手与配置

### 案例 1：Frôstborn (Tarren Mill - EU) —— 大秘境世界总分前列
- **角色大秘境评分**：3,782 分
- **配装核心**：
  - 套装：灾兆墓骑士 4 件套（头、胸、腿、手）
  - 主手武器：制造单手剑 破法者之刃（暴击 / 精通，附魔堕落十字军）
  - 副手武器：锁缚女神之颌（英雄等级 +21 掉落，附魔冰锋符文）
  - 英雄天赋：死亡使者（Deathbringer）
  - 饰品：乌拉泰克的饕餮之心（神话 639） + 共鸣风箱石（神话 639）
- **复盘要点**：
  - 45 秒一波冰柱对齐死神印记，在波次聚怪完毕 3 秒内打满全部印记充能层数，瞬间引爆伤害峰值超 1,400k。
  - 致盲冰雨精准打断关键读条怪，反魔法护罩在高压 AOE 阶段转化为全额符文能量，保持持续站桩输出。

### 案例 2：Koldhart (Illidan - US) —— 纳洛拉克之穴 (Den of Nalorakk) +21 限时 (24分18秒)
- **WCL 报告直达**：`https://www.warcraftlogs.com/reports/sample-frost-den-21`
- **英雄天赋**：死亡使者（Deathbringer）
- **全程秒伤 (DPS)**：304.8k
- **伤害结构占比（Damage Done Breakdown）**：
  1. **湮灭 (Obliterate)**：占整场伤害约 **34.2%**（杀戮机器顺劈暴击为主体）。
  2. **冷酷严冬 (Remorseless Winter)**：占整场伤害约 **20.1%**（汇聚风暴全程高覆盖）。
  3. **死神印记 / 暗霜碎裂 (Reaper's Mark / Grim Reaper)**：占整场伤害约 **18.7%**。
  4. **冰霜幼龙之援 (Frostwyrm's Fury)**：占整场伤害约 **12.5%**（每波大怪规划释放）。
  5. **冰川突进 (Glacial Advance)**：占整场伤害约 **8.3%**（范围多目标泄能顺劈）。
- **节奏与实操特点**：
  - 全程 14 次大波次小怪拉怪中，没有一次出现死神印记空放或提前引爆情况；枯萎凋零的站桩覆盖率达到 88%。
