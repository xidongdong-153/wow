# 冰霜死亡骑士（Frost Death Knight）指南

本专区汇总当前赛季（Midnight Season 1 / 团本 The Venomous Abyss）冰霜死亡骑士的大秘境与团本配置、输出手法与高分日志复盘。

## 专精定位与机制核心

冰霜死亡骑士是依托冰霜伤害、高频杀戮机器暴击与符文能量快速循环的近战输出专精：
1. **符文与能量循环**：通过湮灭（Obliterate）与凛风冲击（Howling Blast / 白霜触发）消耗符文、产生符文能量；通过冰霜打击（Frost Strike）或冰川突进（Glacial Advance）快速泄能，高频触发杀戮机器（Killing Machine）保证高暴击率。
2. **冷酷严冬与范围顺劈**：冷酷严冬（Remorseless Winter）提供无目标上限的持续冰霜光环，配合枯萎凋零（Death and Decay）内湮灭顺劈机制，构成大秘境核心清怪框架。
3. **英雄天赋分化**：
   - **死亡使者（Deathbringer）**：大秘境绝对核心（**98.2%** 使用率，均伤 **296.9k**，最高限时记录 +21），通过死神印记（Reaper's Mark）高频叠层引发暗霜碎裂爆炸，爆发峰值极高。
   - **天启骑士（Rider of the Apocalypse）**：占比 **1.7%**（均伤 249.0k），主打四骑士被动伤害与马背施法机动性，多见于特定史诗团本位移战斗。
4. **团队功能性**：
   - 死亡之握（群拉/单拉聚怪）、窒息（点晕）、致盲冰雨（群体断条/瘫痪）、反魔法护罩（AMS 免控吸伤）、反魔法领域（大罩团队法术减伤）、复活盟友（战复）。

## 属性优先级与配比

### 1. 大秘境属性（高层 19-21 层环境）
- 优先级：力量 > 暴击（Crit） > 精通（Mastery） > 急速（Haste） > 全能（Vers）
- 样本均值指标（基于 73,688 份 +7 至 +21 层有效日志）：
  - 暴击：约 1206 点（第一核心副属性，杀戮机器与死神印记极度依赖暴击）
  - 精通：约 990 点（直接按百分比提升全系冰霜与暗霜伤害）
  - 急速：约 469 点（维持基础符文恢复速度即可，不过度投入）
  - 全能：约 192 点（配装中尽量压低，避免挤占绿字预算）

### 2. 团本史诗属性
- 优先级：力量 > 暴击（1280） > 精通（1040） > 急速（410） > 全能（150）
- 团本单体环境下进一步压缩急速与全能，将暴击与精通堆至极限以拉高冰柱期窗口爆发伤害。
