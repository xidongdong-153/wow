# 死亡骑士（Death Knight）

死亡骑士包含三个专精：
- **邪恶（Unholy）**：近战暗影与暗霜伤害输出者，依赖随从大军、溃烂伤口与疾病造成极高爆发。当前版本大秘境与团本核心输出专精。
- **冰霜（Frost）**：近战冰霜伤害输出者，拥有湮灭与龙息冰龙体系。（待扩展）
- **鲜血（Blood）**：坦克专精，依赖骨髓分裂、灵界打击自疗与符文武器。（待扩展）
