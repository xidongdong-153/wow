# 死亡骑士（Death Knight）

死亡骑士包含三个专精：
- **邪恶（Unholy）**：近战暗影与暗霜伤害输出者，依赖随从大军、溃烂伤口与疾病造成极高爆发。
- **冰霜（Frost）**：近战冰霜伤害输出者，依赖湮灭、冷酷严冬与死神印记造成高额暴击顺劈。
- **鲜血（Blood）**：坦克专精，依赖骨髓分裂、灵界打击自疗、骨盾减伤与萨莱茵血兽输出。
