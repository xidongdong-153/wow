# 鲜血死亡骑士（Blood Death Knight）指南

本专区汇总当前赛季（Midnight Season 1 / 团本 The Venomous Abyss）鲜血死亡骑士的大秘境与团本配置、减伤自疗手法与高分日志复盘。

## 专精定位与机制核心

鲜血死亡骑士是依托骨盾减伤、高额符文自疗与主动伤害转化的顶级坦克专精：
1. **骨盾与符文循环**：通过骨髓分裂（Marrowrend）生成并维持骨盾（Bone Shield）层数提供高额护甲与急速加成；通过心脏打击（Heart Strike）快速产生符文能量。
2. **灵界打击与血盾自疗**：通过灵界打击（Death Strike）将近期承受伤害转化为巨额自身治疗，并生成吸收物理伤害的鲜血护盾（Blood Shield），构成血DK生存的核心防御环。
3. **英雄天赋分化**：
   - **萨莱茵（San'layn）**：大秘境绝对核心（**90.0%** 使用率，均伤 **208.0k**，最高限时记录 +22），吸血鬼打击带来极高被动自疗、急速增益以及血兽引爆的高额伤害。
   - **死亡使者（Deathbringer）**：占比 **9.9%**（均伤 152.6k），偏向物理护甲防御与死神印记直伤。
4. **团队功能性**：
   - 死亡之握（核心聚怪神技）、血魔之握（群体聚怪）、窒息（单体强控）、反魔法护罩与反魔法领域（团队法术大减伤）、战复。

## 属性优先级与配比

### 1. 大秘境属性（高层 20-22 层环境）
- 优先级：力量 > 急速（Haste） > 暴击（Crit） > 精通（Mastery） > 全能（Vers）
- 样本均值指标（基于 478,288 份 +7 至 +22 层有效日志）：
  - 急速：约 939 点（第一核心副属性，决定符文恢复速度、GCD 与骨盾周转流畅度）
  - 暴击：约 783 点（提供招架几率与伤害输出暴击，提升自疗效率）
  - 精通：约 561 点（放大鲜血护盾吸收量与攻强）
  - 全能：约 431 点（提供基础全额硬减伤）

### 2. 团本史诗属性
- 优先级：力量 > 急速（980） > 精通（720） > 全能（510） > 暴击（450）
- 团本由于高额单体首领物理平砍压力，精通（血盾吸收量）和全能权重相对提高，暴击优先级略微下移。
