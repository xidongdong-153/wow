# 鲜血死亡骑士配装指南

基于当前赛季（Midnight Season 1）最新高分榜统计（样本量 478,288 份 +7 至 +22 层有效记录）。

## 1. 套装选择（灾兆墓骑士 4 件套 / Baleful Grave-Knight）

必须优先凑齐 4 件套以激活受到伤害转化为额外符文能量与骨盾强化的核心生存特效。

| 部位 | 装备名称 | 属性 | 大秘境使用率 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| **胸甲** | 灾兆墓骑士的胸甲 (Baleful Grave-Knight's Breastplate) | 精通 / 暴击 | **70.4%** | 高额护甲与基础属性，核心必选 |
| **头部** | 灾兆墓骑士的头盔 (Baleful Grave-Knight's Casque) | 暴击 / 精通 | **65.6%** | 核心必选部位 |
| **护腿** | 灾兆墓骑士的护胫 (Baleful Grave-Knight's Gibbets) | 全能 / 急速 | **62.3%** | 携带坦克核心急速全能，高层首选 |
| **手套** | 灾兆墓骑士的手套 (Baleful Grave-Knight's Deathgrips) | 精通 / 暴击 | **60.9%** | 凑 4 件套稳定部位 |
| **肩部** | 灾兆墓骑士的护肩 (Baleful Grave-Knight's Pauldrons) | 急速 / 精通 | 24.8% | 属性不错，可作为备选部件 |

## 2. 武器推荐

鲜血死亡骑士使用双手武器体系（双手剑 / 双手斧 / 双手长柄）。

- **主流双手武器**：
  - **血骑士战刃 (Blood Knight's Warblade)**：
    - 类别：制造业定制双手武器（锻造制作，主选急速暴击）
    - 使用率：**55.0%**（高层大秘境第一选择）
  - **督军之怒·马泽罗亚 (Maze-roa, Warlord's Fury)**：
    - 类别：团本史诗掉落
    - 使用率：**5.0%**（顶级装等高攻强首选）
  - **回火切肉斧 (Backdraft Cleaver)**：
    - 类别：地下城掉落
    - 使用率：**4.8%**
  - **绽火巨斧 (Bloomforged Greataxe)**：
    - 类别：地下城掉落
    - 使用率：**4.6%**

## 3. 美化方案（Embellishments）

当前版本坦克向主流双美化组合：
- **破法者护腕 (Spellbreaker's Bracers)** 嵌入强化美化 + **暗月徽记：坚韧 / 附魔护甲内衬**（占比约 **62.1%**）。
- 机制简述：高血量阶段提供被动全属性加成，并在承伤尖峰时触发减伤吸收护盾，防止高层小怪死疽与穿刺技能瞬间致死。
