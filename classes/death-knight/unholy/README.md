# 邪恶死亡骑士（Unholy Death Knight）指南

本专区汇总当前赛季（Midnight Season 2 / 团本 The Venomous Abyss）邪恶死亡骑士的大秘境与团本配置、输出手法与高分日志复盘。

## 专精定位与机制核心

邪恶死亡骑士的核心输出机制由三个环构成：
1. **溃烂伤口与爆裂之疡**：通过溃烂打击或被动挂伤口，在枯萎凋零（Death and Decay）内通过天灾打击（Scourge Strike）多目标顺劈并引爆伤口，提供巨量瞬时 AOE 伤害。
2. **随从军团与突变机制**：黑暗突变（Dark Transformation）引爆宠物并配合天启（Apocalypse）拉出大军，产生高额增伤与直伤。
3. **英雄天赋分化**：
   - 大秘境以**萨莱茵（San'layn）**为主流（57.7% 使用率，均伤 311.3k），主打血兽自爆与吸血打击刷新机制。
   - 团本史诗开荒以**天启骑士（Rider of the Apocalypse）**略占优势（52.5% 使用率，均伤 264.3k），时间轴稳定且自带额外硬度与破甲。

## 属性优先级与配比

### 1. 大秘境属性（高层 19-20 层环境）
- 优先级：力量 > 暴击（Crit） > 精通（Mastery） > 急速（Haste） > 全能（Vers）
- 样本均值指标：
  - 暴击：约 1140 点（提高伤口爆裂与直伤暴击，收益最高）
  - 精通：约 1050 点（直接放大暗影与暗霜伤害，提升全系宠物与疾病输出）
  - 急速：约 466 点（保证符文周转手感即可，不过度投入）
  - 全能：约 181 点（尽量规避全能装备）

### 2. 团本史诗属性（单体与转火环境）
- 优先级：力量 > 暴击（1310） > 精通（1140） > 急速（426） > 全能（127）
- 相比大秘境，团本更极化暴击与精通，将全能和急速进一步压缩。
