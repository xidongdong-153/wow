# 织雾武僧（Monk）指南

本专区汇总当前赛季（Midnight Season 2 / 史诗团本烈毒之渊 The Venomous Abyss）织雾武僧的大秘境与团本配置、装备选择、循环手法与高分日志复盘。

## 专精定位与机制核心

织雾武僧的核心战斗机制由三个环构成：
1. **核心循环**：复苏之雾全队智能跳跃，神龙之赐蓄力大秘境瞬满全队，近战古法输出自动转化巨额治疗，天神御尊朱雀大抬血。
2. **套装与构建联动**：当前 4 件套 Serene Master's Gi (安详大师的武僧服) 对核心循环具有质的提升。
3. **英雄天赋分化**：大秘境以**天神御尊（CONDUIT OF THE CELESTIALS）**为主导（95.9% 使用率），具备极高顺劈上限与机制契合度。

## 属性优先级与配比

### 1. 大秘境属性（高层 +18 至 +21 层环境）
- 优先级：智力 > 急速 (1180) > 暴击 (1060) > 全能 (540) > 精通 (220)

### 2. 团本史诗属性（高压单体与开荒环境）
- 优先级：智力 > 急速 (1250) > 暴击 (1080) > 精通 (480) > 全能 (120)
