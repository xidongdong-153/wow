# 酒仙武僧（Monk）指南

本专区汇总当前赛季（Midnight Season 2 / 史诗团本烈毒之渊 The Venomous Abyss）酒仙武僧的大秘境与团本配置、装备选择、循环手法与高分日志复盘。

## 专精定位与机制核心

酒仙武僧的核心战斗机制由三个环构成：
1. **核心循环**：醉拳机制将受到的 80% 物理与魔法伤害分期付款，活血酒瞬间化解红醉拳，天神护佑套盾，祥和大师转化全团护盾。
2. **套装与构建联动**：当前 4 件套 Serene Master's Gi (安详大师的武僧服) 对核心循环具有质的提升。
3. **英雄天赋分化**：大秘境以**祥和大师（MASTER OF HARMONY）**为主导（78.2% 使用率），具备极高顺劈上限与机制契合度。

## 属性优先级与配比

### 1. 大秘境属性（高层 +18 至 +21 层环境）
- 优先级：敏捷 > 急速 (1140) > 暴击 (1050) > 全能 (560) > 精通 (220)

### 2. 团本史诗属性（高压单体与开荒环境）
- 优先级：敏捷 > 急速 (1220) > 暴击 (1060) > 全能 (520) > 精通 (180)
