# 恩护唤魔师（Evoker）指南

本专区汇总当前赛季（Midnight Season 2 / 史诗团本烈毒之渊 The Venomous Abyss）恩护唤魔师的大秘境与团本配置、装备选择、循环手法与高分日志复盘。

## 专精定位与机制核心

恩护唤魔师的核心战斗机制由三个环构成：
1. **核心循环**：逆转小队回春维持黄金时刻，回响复制下一次治疗法术，梦境吐息与精神之花蓄力抬血，翡翠交融免控群拉血线。
2. **套装与构建联动**：当前 4 件套 Dragonflight Ascendancy (巨龙的统御之姿) 对核心循环具有质的提升。
3. **英雄天赋分化**：大秘境以**塑焰者（FLAMESHAPER）**为主导（95.7% 使用率），具备极高顺劈上限与机制契合度。

## 属性优先级与配比

### 1. 大秘境属性（高层 +18 至 +21 层环境）
- 优先级：智力 > 精通 (1220) > 暴击 (1050) > 急速 (520) > 全能 (180)

### 2. 团本史诗属性（高压单体与开荒环境）
- 优先级：智力 > 精通 (1280) > 暴击 (1080) > 急速 (460) > 全能 (120)
