# 防护圣骑士（Protection Paladin）指南

本专区汇总当前赛季（Midnight Season 1 / 团本 The Venomous Abyss）防护圣骑士的大秘境与团本配置、减伤循环与高分日志复盘。

## 专精定位与机制核心

防护圣骑士是依托正义之盾护甲覆盖、奉献站桩常驻减伤、神圣能量快速周转与全方位团队保护的硬度与功能性兼备坦克：
1. **神圣能量与盾牌格挡**：通过祝福之锤（Blessed Hammer）、审判（Judgment）产生神圣能量；消耗 3 点神圣能量施放正义之盾（Shield of the Righteous），造成神圣伤害并极大提升自身护甲。
2. **复仇者之盾与奉献**：复仇者之盾（Avenger's Shield / 飞盾）可在多目标之间弹跳打断并提供全额吸收护盾；奉献（Consecration）提供脚下站桩硬减伤与精通加成。
3. **英雄天赋分化**：
   - **铸光者（Lightsmith）**：大秘境绝对核心（**79.4%** 使用率，均伤 **154.3k**，最高限时记录 +20），通过圣圣武装（Holy Bulwark）与铸光圣兵（Sacred Weapon）赋予自身及队友极高吸收护盾与直伤增益。
   - **圣殿骑士（Templar）**：占比 **20.5%**（均伤 130.8k），主打圣殿天锤的爆发与短轴直伤。
4. **全方位团队保护**：
   - 保护祝福（物理免疫）、自由祝福（免疫减速/定身）、牺牲祝福（分担队友伤害）、圣疗术（瞬抬满血）、盲目之光（群盲）、制裁之锤（强晕）、清毒术。

## 属性优先级与配比

### 1. 大秘境属性（高层 19-21 层环境）
- 优先级：力量 > 急速（Haste） > 暴击（Crit） > 精通（Mastery） > 全能（Vers）
- 样本均值指标（基于 279,438 份 +7 至 +21 层有效日志）：
  - 急速：约 991 点（第一核心副属性，直接决定 GCD、转锤子与审判 CD 以及盾击覆盖率）
  - 暴击：约 875 点（提升招架几率与输出暴击，兼具攻防收益）
  - 精通：约 522 点（提高奉献内减伤百分比与格挡几率）
  - 全能：约 296 点（配装中平滑承伤，不特意堆叠）

### 2. 团本史诗属性
- 优先级：力量 > 急速（1020） > 精通（680） > 全能（410） > 暴击（520）
- 团本由于单体物理重压更频繁，精通（奉献减伤与格挡率）重要性提升。
