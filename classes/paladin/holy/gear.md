# 神圣圣骑士配装指南

基于当前赛季（Midnight Season 1）最新高分榜统计（样本量 396,441 份 +7 至 +21 层有效记录）。

## 1. 套装选择（圣火 4 件套 / Consecrated Flame）

必须优先凑齐 4 件套以激活神圣震击双暴击判定与荣耀圣令顺劈抬血的核心治疗特效。

| 部位 | 装备名称 | 属性 | 大秘境使用率 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| **胸甲** | 圣火之堡垒 (Bulwark of the Consecrated Flame) | 精通 / 急速 | **69.5%** | 极品绿字组合，核心必选部位 |
| **头部** | 圣火战盔 (Warhelm of the Consecrated Flame) | 暴击 / 精通 | **65.8%** | 核心必选部位 |
| **肩部** | 圣火护肩 (Pauldrons of the Consecrated Flame) | 暴击 / 精通 | **62.8%** | 核心必选部位 |

## 2. 武器与盾牌推荐

神圣圣骑士主流采用智力单手武器 + 智力盾牌体系，提供高额护甲与法术强度。

- **主手武器**：

    - 类别：团本史诗掉落

- **副手盾牌**：
  - **破法者之拒 (Spellbreaker's Rebuke)**：
    - 类别：制造业定制智力盾牌（锻造制作，高急速高精通）

  - **风暴之庇 (Tempest's Shelter)**：
    - 类别：地下城掉落

  - **泰达希尔的牺牲 (Teldrassil's Sacrifice)**：

## 3. 美化方案（Embellishments）

当前版本大秘境治疗向主流双美化组合：
- **破法者护腕 (Spellbreaker's Bracers)** 制作强化 + **暗月徽记：升腾 / 附魔护甲内衬**（占比约 **66.2%**）。
- 机制简述：在队友生命值处于危险区间时触发高额被动智力加成，并在持续战斗中平滑回蓝，强化美德道标期间的瞬间爆发抬血峰值。
