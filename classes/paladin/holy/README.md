# 神圣圣骑士（Holy Paladin）指南

本专区汇总当前赛季（Midnight Season 1 / 团本 The Venomous Abyss）神圣圣骑士的大秘境与团本配置、近战抬血手法与高分日志复盘。

## 专精定位与机制核心

神圣圣骑士是依托近战位输出转化治疗、高频神圣能量获取与全能团队保护的顶级治疗专精：
1. **神圣能量与圣光双循环**：通过神圣震击（Holy Shock）、十字军打击（Crusader Strike）快速获取神圣能量；通过荣耀圣令（Word of Glory / 单体大抬）或黎明之光（Light of Dawn / 锥形群体群抬）倾泻能量。
2. **道标机制与精通近战收益**：美德道标（Beacon of Virtue）可在队伍面临 AOE 尖峰时瞬间复制高额治疗至全队 4 名队友；精通：光明使者（Mastery: Lightbringer）使靠近受治疗者的治疗量显著提升。
3. **英雄天赋分化**：
   - **太阳先锋（Herald of the Sun）**：大秘境主流核心（**69.9%** 使用率，HPS **157.6k**，DPS 30.0k，最高限时记录 +21），通过神圣震击触发晨光（Dawnlight）光束，提供强大的多目标持续智能回血与被动顺劈伤害。
   - **铸光者（Lightsmith）**：占比 **30.0%**（HPS 178.0k），主打圣圣武装与神圣武器赋予的高额团队吸收护盾，偏向防猝死与硬度保障。
4. **团队功能性**：
   - 光环掌握（Devotion Aura Mastery，核心团队大减伤）、保护祝福、牺牲祝福、自由祝福、圣疗术、清毒术、制裁之锤、盲目之光、战复。

## 属性优先级与配比

### 1. 大秘境属性（高层 19-21 层环境）
- 优先级：智力 > 急速（Haste） > 精通（Mastery） > 暴击（Crit） > 全能（Vers）
- 样本均值指标（基于 396,441 份 +7 至 +21 层有效日志）：
  - 急速：约 939 点（第一核心副属性，缩短神圣震击 CD 与 GCD，加快圣能周转）
  - 精通：约 779 点（近战位站位治疗百分比提升，放大直抬峰值）
  - 暴击：约 714 点（神圣震击双倍暴击率，触发圣光灌注）
  - 全能：约 305 点（配装中平滑承伤，不特意堆叠）

### 2. 团本史诗属性
- 优先级：智力 > 暴击（880） > 精通（850） > 急速（780） > 全能（260）
- 团本由于站位更加分散且法力续航要求高，暴击与精通权重上升，急速适度控制以防空蓝。
