# 圣骑士（Paladin）

圣骑士包含三个专精：
- **惩戒（Retribution）**：近战神圣伤害输出者，拥有极高的神圣风暴顺劈、爆发能力与全方位的团队保护功能性（圣疗、保护、牺牲、自由）。
- **防护（Protection）**：坦克专精，依赖正义之盾、奉献站桩减伤、飞盾群断与铸光者团队护盾。
- **神圣（Holy）**：治疗专精，依赖近战位输出转化治疗、神圣震击、美德道标与太阳先锋晨光射线抬血。
