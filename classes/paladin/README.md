# 圣骑士（Paladin）

圣骑士包含三个专精：
- **惩戒（Retribution）**：近战神圣伤害输出者，拥有极高的神圣风暴顺劈、爆发能力与全方位的团队保护功能性（圣疗、保护、牺牲、自由）。
- **防护（Protection）**：坦克专精，依赖正义之盾、奉献减伤与飞盾群断打断。（待扩展）
- **神圣（Holy）**：治疗专精，依赖神圣震击、黎明之光与美德道标进行近战位治疗。（待扩展）
