# 生存猎人（Hunter）指南

本专区汇总当前赛季（Midnight Season 2 / 史诗团本烈毒之渊 The Venomous Abyss）生存猎人的大秘境与团本配置、装备选择、循环手法与高分日志复盘。

## 专精定位与机制核心

生存猎人的核心战斗机制由三个环构成：
1. **核心循环**：野火炸弹核心 AOE，利刃绝杀快速泄能刷炸弹，协同进攻大幅提高宠物与本体爆发协同。
2. **套装与构建联动**：当前 4 件套 Beaststalker's Guile (野兽追猎者的奇谋) 对核心循环具有质的提升。
3. **英雄天赋分化**：大秘境以**哨兵（SENTINEL）**为主导（66.5% 使用率），具备极高顺劈上限与机制契合度。

## 属性优先级与配比

### 1. 大秘境属性（高层 +18 至 +21 层环境）
- 优先级：敏捷 > 暴击 (1140) > 急速 (1080) > 精通 (580) > 全能 (170)

### 2. 团本史诗属性（高压单体与开荒环境）
- 优先级：敏捷 > 暴击 (1210) > 急速 (1060) > 精通 (540) > 全能 (120)
