# 射击猎人（Hunter）指南

本专区汇总当前赛季（Midnight Season 2 / 史诗团本烈毒之渊 The Venomous Abyss）射击猎人的大秘境与团本配置、装备选择、循环手法与高分日志复盘。

## 专精定位与机制核心

射击猎人的核心战斗机制由三个环构成：
1. **核心循环**：多重射击激活技巧射击顺劈，百发百中爆发期瞄准与急速射击无缝连击，哨兵猫头鹰印记持续轰炸。
2. **套装与构建联动**：当前 4 件套 Beaststalker's Guile (野兽追猎者的奇谋) 对核心循环具有质的提升。
3. **英雄天赋分化**：大秘境以**哨兵（SENTINEL）**为主导（97.3% 使用率），具备极高顺劈上限与机制契合度。

## 属性优先级与配比

### 1. 大秘境属性（高层 +18 至 +21 层环境）
- 优先级：敏捷 > 暴击 (1180) > 精通 (1040) > 急速 (550) > 全能 (160)

### 2. 团本史诗属性（高压单体与开荒环境）
- 优先级：敏捷 > 暴击 (1260) > 精通 (1020) > 急速 (500) > 全能 (110)
