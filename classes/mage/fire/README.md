# 火焰法师（Mage）指南

本专区汇总当前赛季（Midnight Season 2 / 史诗团本烈毒之渊 The Venomous Abyss）火焰法师的大秘境与团本配置、装备选择、循环手法与高分日志复盘。

## 专精定位与机制核心

火焰法师的核心战斗机制由三个环构成：
1. **核心循环**：燃烧百分百暴击窗口爆发，不死鸟之焰与火焰冲击产生热力迸发，日怒大火凤带来高额顺劈加成。
2. **套装与构建联动**：当前 4 件套 Spire-Weaver's Regalia (尖塔编织者的礼服) 对核心循环具有质的提升。
3. **英雄天赋分化**：大秘境以**日怒（SUNFURY）**为主导（97.5% 使用率），具备极高顺劈上限与机制契合度。

## 属性优先级与配比

### 1. 大秘境属性（高层 +18 至 +21 层环境）
- 优先级：智力 > 急速 (1210) > 全能 (850) > 精通 (640) > 暴击 (350)

### 2. 团本史诗属性（高压单体与开荒环境）
- 优先级：智力 > 急速 (1260) > 全能 (820) > 精通 (650) > 暴击 (320)
