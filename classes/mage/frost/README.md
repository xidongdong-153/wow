# 冰霜法师（Mage）指南

本专区汇总当前赛季（Midnight Season 2 / 史诗团本烈毒之渊 The Venomous Abyss）冰霜法师的大秘境与团本配置、装备选择、循环手法与高分日志复盘。

## 专精定位与机制核心

冰霜法师的核心战斗机制由三个环构成：
1. **核心循环**：冰冷血脉全时覆盖，冰霜宝珠高频产生冰指，彗星风暴与魔导士碎冰裂变提供极高密集顺劈。
2. **套装与构建联动**：当前 4 件套 Spire-Weaver's Regalia (尖塔编织者的礼服) 对核心循环具有质的提升。
3. **英雄天赋分化**：大秘境以**魔导士（SPELLSLINGER）**为主导（75.5% 使用率），具备极高顺劈上限与机制契合度。

## 属性优先级与配比

### 1. 大秘境属性（高层 +18 至 +21 层环境）
- 优先级：智力 > 暴击 (1180) > 急速 (1020) > 精通 (620) > 全能 (150)

### 2. 团本史诗属性（高压单体与开荒环境）
- 优先级：智力 > 暴击 (1250) > 急速 (990) > 精通 (600) > 全能 (110)
