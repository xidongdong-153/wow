# 守护德鲁伊（Druid）指南

本专区汇总当前赛季（Midnight Season 2 / 史诗团本烈毒之渊 The Venomous Abyss）守护德鲁伊的大秘境与团本配置、装备选择、循环手法与高分日志复盘。

## 专精定位与机制核心

守护德鲁伊的核心战斗机制由三个环构成：
1. **核心循环**：痛击与裂伤保持铁鬃常驻 4-6 层，化身期间大波次战神，艾露恩之选月火持续吸血化解物理与魔法死线。
2. **套装与构建联动**：当前 4 件套 Dreamgrove's Rebirth (梦境之林的重生) 对核心循环具有质的提升。
3. **英雄天赋分化**：大秘境以**艾露恩之选（ELUNE'S CHOSEN）**为主导（99.1% 使用率），具备极高顺劈上限与机制契合度。

## 属性优先级与配比

### 1. 大秘境属性（高层 +18 至 +21 层环境）
- 优先级：敏捷 > 急速 (1180) > 全能 (1050) > 精通 (540) > 暴击 (220)

### 2. 团本史诗属性（高压单体与开荒环境）
- 优先级：敏捷 > 全能 (1240) > 急速 (1120) > 精通 (480) > 暴击 (180)
