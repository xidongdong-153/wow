# 神圣牧师（Priest）指南

本专区汇总当前赛季（Midnight Season 2 / 史诗团本烈毒之渊 The Venomous Abyss）神圣牧师的大秘境与团本配置、装备选择、循环手法与高分日志复盘。

## 专精定位与机制核心

神圣牧师的核心战斗机制由三个环构成：
1. **核心循环**：愈合祷言弹跳维持，圣言术静单体瞬抬残血，圣言术灵地面圈刷，神谕者预见符文给全队赋予防猝死免伤。
2. **套装与构建联动**：当前 4 件套 Sanctified Oracle's Vestments (受祝神谕者的外衣) 对核心循环具有质的提升。
3. **英雄天赋分化**：大秘境以**神谕者（ORACLE）**为主导（95.8% 使用率），具备极高顺劈上限与机制契合度。

## 属性优先级与配比

### 1. 大秘境属性（高层 +18 至 +21 层环境）
- 优先级：智力 > 暴击 (1180) > 急速 (1040) > 全能 (560) > 精通 (220)

### 2. 团本史诗属性（高压单体与开荒环境）
- 优先级：智力 > 精通 (1240) > 暴击 (1060) > 急速 (480) > 全能 (120)
