# 暗影牧师（Priest）指南

本专区汇总当前赛季（Midnight Season 2 / 史诗团本烈毒之渊 The Venomous Abyss）暗影牧师的大秘境与团本配置、装备选择、循环手法与高分日志复盘。

## 专精定位与机制核心

暗影牧师的核心战斗机制由三个环构成：
1. **核心循环**：吸血鬼之触与暗言术痛快速铺满，噬灵疫病狂乱泄能，虚空爆发配合执政官光晕大范围穿透暗影 AOE。
2. **套装与构建联动**：当前 4 件套 Sanctified Oracle's Vestments (受祝神谕者的外衣) 对核心循环具有质的提升。
3. **英雄天赋分化**：大秘境以**执政官（ARCHON）**为主导（62.3% 使用率），具备极高顺劈上限与机制契合度。

## 属性优先级与配比

### 1. 大秘境属性（高层 +18 至 +21 层环境）
- 优先级：智力 > 急速 (1210) > 精通 (1050) > 暴击 (520) > 全能 (180)

### 2. 团本史诗属性（高压单体与开荒环境）
- 优先级：智力 > 急速 (1260) > 精通 (1080) > 暴击 (480) > 全能 (120)
