# 武器战士（Arms Warrior）指南

本专区汇总当前赛季（Midnight Season 2 / 史诗团本烈毒之渊 The Venomous Abyss）武器战士的大秘境与团本配置、装备选择、输出手法与高分日志复盘。

## 专精定位与机制核心

武器战士的核心输出机制由三个环构成：
1. **致死打击与重伤压制**：通过压制（Overpower）强化致死打击（Mortal Strike），在目标身上维持高覆盖重伤流血，并在斩杀阶段通过强化斩杀实现断层爆发。
2. **横扫顺劈与剑刃风暴**：开启横扫攻击（Sweeping Strikes）使单体循环技能完美复制至额外副目标，配合剑刃风暴（Bladestorm）提供极高密度的瞬时多目标峰值。
3. **英雄天赋分化**：
   - 大秘境以**屠戮者（Slayer）**为主导（99.8% 绝对主流，验证最高限时 +22 层，均伤 303.2k），剑刃风暴高频触发屠戮斩击，标记弱点使多目标物理顺劈无上限扩散。
   - 单体首领与小幅爆发环境以**巨神（Colossus）**为可选方案，主打巨神打击高额破甲与单发压制爆发。

## 属性优先级与配比

### 1. 大秘境属性（高层 +18 至 +22 层环境）
- 优先级：力量 > 暴击（Crit） > 急速（Haste） > 精通（Mastery） > 全能（Vers）
- 样本均值指标：
  - 暴击：约 1161 点（大幅提升致死打击与屠戮斩击暴击率，核心收益第一属性）
  - 急速：约 943 点（加快怒气回馈、压制充能与公共冷却周转）
  - 精通：约 523 点（提供重伤流血加深与被动物理增伤）
  - 全能：约 200 点（规避纯全能装备，保留散件提供常驻减伤即可）

### 2. 团本史诗属性（单体与转阶段斩杀环境）
- 优先级：力量 > 暴击（1280） > 急速（980） > 精通（490） > 全能（150）
- 相比大秘境，团本更极化暴击率，将斩杀期的怒气转化与猝死触发率拉至最大。
