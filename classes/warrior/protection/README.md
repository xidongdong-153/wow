# 防护战士（Protection Warrior）指南

本专区汇总当前赛季（Midnight Season 2 / 史诗团本烈毒之渊 The Venomous Abyss）防护战士的大秘境与团本配置、装备选择、坦克减伤循环与高分日志复盘。

## 专精定位与机制核心

防护战士作为重装物理免伤坦克的标杆，核心防御架构由三个机制支柱构成：
1. **盾牌格挡与精确格挡**：盾牌格挡（Shield Block）提供 100% 物理格挡几率，精通直接转化为精确格挡（Critical Block，格挡减免伤害由 30% 翻倍至 60%），在面对高频物理普攻与顺劈怪群时硬度极高。
2. **无视苦痛吸收盾**：无视苦痛（Ignore Pain）消耗怒气化解即将受到的 50% 伤害，与盾牌格挡形成“物理硬格挡 + 全系吸收盾”双重减伤矩阵。
3. **英雄天赋分化**：
   - 大秘境以**山丘领主（Mountain Thane）**为主导（96.5% 绝对统治，验证最高限时 +19 层），雷霆一击与雷霆打击释放毁灭性风暴，大幅提高怒气周转与自保硬度。
   - 纯物理重击首领以**巨神（Colossus）**为备选（3.4% 使用率），主打巨神拆解强化盾猛单次格挡与破甲增幅。

## 属性优先级与生存折算

### 1. 大秘境属性（高层 +18 至 +20 层环境）
- 优先级：急速（Haste） > 精通（Mastery） > 暴击（Crit） > 全能（Vers）
- 属性生存折算逻辑：
  - **急速**：核心第一生存属性。压低盾牌猛击与雷霆一击 CD，极大增加怒气获取速率，使盾牌格挡实现 100% 全时覆盖。
  - **精通**：直接提升攻击强度并转化为**精确格挡几率**（1 点精通约提供 1.2% 精确格挡），高精通防战格挡减伤达到 60% 质变。
  - **暴击**：暴击直接等额转化为**招架几率（Parry）**，提供被动完全免伤。
  - **全能**：提供常驻硬减伤，但边际收益低于急速精通。
- 样本均值指标：
  - 急速：约 1140 点（保证盾牌格挡常驻断档率 < 1%）
  - 精通：约 980 点（精确格挡率达到 65% 以上）
  - 暴击：约 460 点
  - 全能：约 210 点

### 2. 团本史诗属性（高压死刑抗怪环境）
- 优先级：急速（1200） > 精通（1050） > 全能（380） > 暴击（320）
