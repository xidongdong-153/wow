# 狂暴战士（Fury Warrior）指南

本专区汇总当前赛季（Midnight Season 2 / 史诗团本烈毒之渊 The Venomous Abyss）狂暴战士的大秘境与团本配置、装备选择、输出手法与高分日志复盘。

## 专精定位与机制核心

狂暴战士的核心输出机制由三个环构成：
1. **激怒覆盖与嗜血狂热**：通过施放暴怒（Rampage）或嗜血（Bloodthirst）触发暴击激活激怒（Enrage），常驻提供大量急速、伤害加成与受击减伤，激怒覆盖率直接决定狂暴战的生死与伤害底线。
2. **旋风斩顺劈机制**：施放旋风斩（Whirlwind）后，接下来的 4 次单体攻击（怒击、嗜血、暴怒）自动对周围额外至多 4 个目标造成伤害，实现零门槛的多目标顺劈转换。
3. **英雄天赋分化**：
   - 大秘境以**屠戮者（Slayer）**为主流（74.7% 使用率，最高限时 +20 层，均伤 278.4k），大幅强化剑刃风暴期间的屠戮旋风与暗影物理顺劈。
   - 大波次雷霆与护甲联动环境以**山丘领主（Mountain Thane）**为备选（25.2% 使用率），主打雷霆一击触发雷霆打击爆发。

## 属性优先级与配比

### 1. 大秘境属性（高层 +18 至 +20 层环境）
- 优先级：力量 > 急速（Haste） > 精通（Mastery） > 暴击（Crit） > 全能（Vers）
- 样本均值指标：
  - 急速：约 1180 点（核心手感属性，压低 GCD，加快平砍产怒与嗜血回旋）
  - 精通：约 960 点（极大提升激怒期间的所有伤害加成）
  - 暴击：约 540 点（适度提升嗜血触发激怒的概率）
  - 全能：约 190 点（规避纯全能部件）

### 2. 团本史诗属性（单体与高压纯木桩环境）
- 优先级：力量 > 急速（1250） > 精通（1080） > 暴击（480） > 全能（120）
