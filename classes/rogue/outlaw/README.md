# 狂徒潜行者（Rogue）指南

本专区汇总当前赛季（Midnight Season 2 / 史诗团本烈毒之渊 The Venomous Abyss）狂徒潜行者的大秘境与团本配置、装备选择、循环手法与高分日志复盘。

## 专精定位与机制核心

狂徒潜行者的核心战斗机制由三个环构成：
1. **核心循环**：剑刃乱舞常驻顺劈，命运骨骰提供高额全能与连击点，冲动极速回能，欺诈者假动作千刀万剐。
2. **套装与构建联动**：当前 4 件套 Shadowblade's Lethality (影刃的致命之触) 对核心循环具有质的提升。
3. **英雄天赋分化**：大秘境以**欺诈者（TRICKSTER）**为主导（99.6% 使用率），具备极高顺劈上限与机制契合度。

## 属性优先级与配比

### 1. 大秘境属性（高层 +18 至 +21 层环境）
- 优先级：敏捷 > 全能 (1150) > 急速 (1080) > 暴击 (560) > 精通 (210)

### 2. 团本史诗属性（高压单体与开荒环境）
- 优先级：敏捷 > 全能 (1220) > 急速 (1040) > 暴击 (520) > 精通 (180)
