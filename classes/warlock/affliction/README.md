# 痛苦术士（Warlock）指南

本专区汇总当前赛季（Midnight Season 2 / 史诗团本烈毒之渊 The Venomous Abyss）痛苦术士的大秘境与团本配置、装备选择、循环手法与高分日志复盘。

## 专精定位与机制核心

痛苦术士的核心战斗机制由三个环构成：
1. **核心循环**：诡异魅影群体挂痛楚，全目标保持腐蚀术与痛苦无常，连打狂欢引爆全场 Dot，灵魂收割者斩杀收割。
2. **套装与构建联动**：当前 4 件套 Demonbinder's Raiment (缚魔者的法衣) 对核心循环具有质的提升。
3. **英雄天赋分化**：大秘境以**灵魂收割者（SOUL HARVESTER）**为主导（91.5% 使用率），具备极高顺劈上限与机制契合度。

## 属性优先级与配比

### 1. 大秘境属性（高层 +18 至 +21 层环境）
- 优先级：智力 > 精通 (1180) > 急速 (1060) > 暴击 (520) > 全能 (180)

### 2. 团本史诗属性（高压单体与开荒环境）
- 优先级：智力 > 精通 (1260) > 急速 (1080) > 暴击 (480) > 全能 (120)
