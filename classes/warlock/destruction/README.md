# 毁灭术士（Warlock）指南

本专区汇总当前赛季（Midnight Season 2 / 史诗团本烈毒之渊 The Venomous Abyss）毁灭术士的大秘境与团本配置、装备选择、循环手法与高分日志复盘。

## 专精定位与机制核心

毁灭术士的核心战斗机制由三个环构成：
1. **核心循环**：献祭多目标挂起，浩劫双目标复制混乱之箭，召唤地狱火大砸波次，雨火倾泻配合恶魔修习者流星雨。
2. **套装与构建联动**：当前 4 件套 Demonbinder's Raiment (缚魔者的法衣) 对核心循环具有质的提升。
3. **英雄天赋分化**：大秘境以**恶魔修习者（DIABOLIST）**为主导（83.4% 使用率），具备极高顺劈上限与机制契合度。

## 属性优先级与配比

### 1. 大秘境属性（高层 +18 至 +21 层环境）
- 优先级：智力 > 急速 (1160) > 精通 (1080) > 暴击 (540) > 全能 (180)

### 2. 团本史诗属性（高压单体与开荒环境）
- 优先级：智力 > 急速 (1240) > 精通 (1090) > 暴击 (490) > 全能 (120)
