# 恶魔学识术士（Warlock）指南

本专区汇总当前赛季（Midnight Season 2 / 史诗团本烈毒之渊 The Venomous Abyss）恶魔学识术士的大秘境与团本配置、装备选择、循环手法与高分日志复盘。

## 专精定位与机制核心

恶魔学识术士的核心战斗机制由三个环构成：
1. **核心循环**：暗影箭与恶魔之核高效攒片，古尔丹之手倾泻小鬼大军，召唤恶魔暴君延长军团，恶魔修习者主宰深渊践踏。
2. **套装与构建联动**：当前 4 件套 Demonbinder's Raiment (缚魔者的法衣) 对核心循环具有质的提升。
3. **英雄天赋分化**：大秘境以**恶魔修习者（DIABOLIST）**为主导（99.8% 使用率），具备极高顺劈上限与机制契合度。

## 属性优先级与配比

### 1. 大秘境属性（高层 +18 至 +21 层环境）
- 优先级：智力 > 急速 (1180) > 暴击 (1040) > 精通 (580) > 全能 (160)

### 2. 团本史诗属性（高压单体与开荒环境）
- 优先级：智力 > 急速 (1250) > 暴击 (1060) > 精通 (540) > 全能 (110)
