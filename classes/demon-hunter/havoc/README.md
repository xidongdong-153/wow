# 浩劫恶魔猎手（Demon Hunter）指南

本专区汇总当前赛季（Midnight Season 2 / 史诗团本烈毒之渊 The Venomous Abyss）浩劫恶魔猎手的大秘境与团本配置、装备选择、循环手法与高分日志复盘。

## 专精定位与机制核心

浩劫恶魔猎手的核心战斗机制由三个环构成：
1. **核心循环**：恶魔之咬/之刃高效产怒，眼棱引导大范围喷火并延长变身，刃舞/死亡横扫高频释放，恶魔追击单体重创。
2. **套装与构建联动**：当前 4 件套 Chaosfiend's Shroud (混魔的寿衣) 对核心循环具有质的提升。
3. **英雄天赋分化**：大秘境以**奥达奇收割者（ALDRACHI REAVER）**为主导（0.8% 使用率），具备极高顺劈上限与机制契合度。

## 属性优先级与配比

### 1. 大秘境属性（高层 +18 至 +21 层环境）
- 优先级：敏捷 > 暴击 (1210) > 精通 (1050) > 急速 (520) > 全能 (180)

### 2. 团本史诗属性（高压单体与开荒环境）
- 优先级：敏捷 > 暴击 (1260) > 精通 (1080) > 急速 (460) > 全能 (120)
