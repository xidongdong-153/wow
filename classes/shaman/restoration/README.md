# 恢复萨满祭司（Shaman）指南

本专区汇总当前赛季（Midnight Season 2 / 史诗团本烈毒之渊 The Venomous Abyss）恢复萨满祭司的大秘境与团本配置、装备选择、循环手法与高分日志复盘。

## 专精定位与机制核心

恢复萨满祭司的核心战斗机制由三个环构成：
1. **核心循环**：激流保持全队先祖复苏，涌动图腾常驻地面群抬，灵魂链接图腾平衡全团血量化解灭团死线。
2. **套装与构建联动**：当前 4 件套 Elemental Ascendant's Harness (元素升腾者的铠甲) 对核心循环具有质的提升。
3. **英雄天赋分化**：大秘境以**图腾巨擘（TOTEMIC）**为主导（97.7% 使用率），具备极高顺劈上限与机制契合度。

## 属性优先级与配比

### 1. 大秘境属性（高层 +18 至 +21 层环境）
- 优先级：智力 > 暴击 (1150) > 全能 (1040) > 精通 (580) > 急速 (220)

### 2. 团本史诗属性（高压单体与开荒环境）
- 优先级：智力 > 精通 (1220) > 暴击 (1060) > 全能 (480) > 急速 (180)
