# 元素萨满祭司（Shaman）指南

本专区汇总当前赛季（Midnight Season 2 / 史诗团本烈毒之渊 The Venomous Abyss）元素萨满祭司的大秘境与团本配置、装备选择、循环手法与高分日志复盘。

## 专精定位与机制核心

元素萨满祭司的核心战斗机制由三个环构成：
1. **核心循环**：烈焰震击多目标铺展，闪电链高频触发熔岩涌动与能量获取，先知召唤先祖复制大地震击与地震术。
2. **套装与构建联动**：当前 4 件套 Elemental Ascendant's Harness (元素升腾者的铠甲) 对核心循环具有质的提升。
3. **英雄天赋分化**：大秘境以**先知（FARSEER）**为主导（99.4% 使用率），具备极高顺劈上限与机制契合度。

## 属性优先级与配比

### 1. 大秘境属性（高层 +18 至 +21 层环境）
- 优先级：智力 > 精通 (1160) > 急速 (1050) > 暴击 (580) > 全能 (180)

### 2. 团本史诗属性（高压单体与开荒环境）
- 优先级：智力 > 精通 (1240) > 急速 (1080) > 暴击 (520) > 全能 (120)
