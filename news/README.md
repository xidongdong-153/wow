本目录归档魔兽世界官方公告、暴雪蓝贴动态、全职业大秘境天梯突破、史诗团本攻坚进度、39 专精流派动向与词缀轮换简报。

## 1. 全职业资讯规范与出处标注标准

为确保资讯的全面性、客观性与时效真实性，每篇每日资讯文档必须遵守以下规范：

1. **全职业与全天赋全景监控原则（强制遵守）**：
   - 严禁仅关注死亡骑士、圣骑士等个别职业，必须建立覆盖全 13 职业 39+ 专精的情报雷达。
   - **大秘境高层突破战报**：不仅通报层数与耗时，必须完整解构队伍 5 个专精的角色分工（坦克、治疗、近战、远程、功能位）及其战术协同。
   - **全职业天梯异动与黑马专精**：每日追踪天梯上升/下降最显著的专精，挖掘战士、萨满、潜行者、武僧、恶魔猎手、术士、猎人、法师、德鲁伊、牧师、唤魔师等全职业的实战亮眼表现。
   - **英雄天赋实战流派变迁**：跟踪各职业双英雄天赋在实战中的分化动向与首选倾向。
2. **结构化来源元数据（Front Matter）**：
   - 顶部 YAML Front Matter 中必须包含 `sources` 列表字段，记录资讯涉及的数据源名称与直达链接。
3. **正文双重出处标注**：
   - **段落内嵌出处**：每个资讯条目下方必须标注“出处直达”，提供直接验证的超链接，杜绝无据推测。
   - **文末验证汇总表**：文章末尾必须设立“引用出处与验证源汇总”表格，按序号列出资讯主题、数据平台名称与绝对 URL。
4. **文案客观性（遵循 xdd-plain-docs）**：
   - 严禁任何 emoji。
   - 纯事实记录：直接陈述角色名、服务器、限时层数、秒伤数值与机制事实，禁止夸大渲染。
5. **归档与防覆盖**：
   - 按月份建立子目录 `news/YYYY-MM/`，按天生成 `YYYY-MM-DD.md`。
   - 严禁覆盖历史旧日记录，历史资讯作为版本生态演进的持久快照。
