# 职业强度排行榜（Tier Lists）

本目录每日归档魔兽世界大秘境与团本的各专精强度天梯排行。

## 评估维度与标准

- **S 级（Meta 核心）**：出场率最高、伤害上限最强或拥有不可替代的团队功能性。
- **A 级（强力主力）**：高分段与史诗开荒中坚力量，机制与伤害表现优秀。
- **B 级（常规可用）**：能稳定完成高层或史诗击杀，但相对缺乏爆发或硬生存支撑。
- **C 级（弱势专精）**：数值落后或机制受当前赛季词缀与副本设计克制。

## 目录结构

- `mythic-plus/`：大秘境强度天梯，按天归档（`YYYY-MM-DD.md`）。
- `raid/`：团本史诗难度强度天梯，按天归档（`YYYY-MM-DD.md`）。
